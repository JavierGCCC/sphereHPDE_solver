# sphereHPDE_solver

`sphereHPDE_solver` is a MATLAB code for the numerical solution of heat diffusion in spherical geometries.

The thermal problem is solved using a Crank–Nicolson finite-difference scheme with explicit treatment of the origin through a ghost-node formulation. The solver provides the full spatio-temporal temperature distribution inside the nanoparticle and the surrounding medium.

Version **v1.0.0** focuses on homogeneous spherical nanoparticles embedded in a homogeneous surrounding medium and introduces the coupling between optical absorption and thermal diffusion.

## Main features

The current implementation includes:

- Numerical solution of the spherical heat diffusion equation using a Crank–Nicolson finite-difference scheme.
- Full spatio-temporal temperature field inside the nanoparticle and surrounding medium.
- Independent thermophysical properties for the nanoparticle and surrounding medium.
- Finite interfacial thermal conductance (ITC) at the particle–medium interface.
- Optical absorption cross-section calculated using Mie theory.
- Wavelength-dependent optical properties obtained from interpolated material data.
- Mie calculations performed using the third-party MATLAB package **MatScat**.
- Quasi-static approximation for comparison with the full Mie solution.
- Analytical estimation of the steady-state maximum temperature increase.
- Example comparing the numerical thermal solution with the quasi-static analytical prediction.
- Matrix-conditioning procedure for improving the numerical solution of the Crank–Nicolson system.
- Initialization routine for automatically configuring the MATLAB paths required by the solver.

The current release is restricted to **homogeneous spherical particles**. Support for stratified and core-shell spherical nanoparticles is planned for future versions.

## Repository initialization

Before using the solver, initialize the required MATLAB paths by running:

```matlab
initialize;
```

The initialization routine makes the solver modules and required MatScat routines available in the current MATLAB session.

Example scripts are provided in the `examples/` directory.

## Optical absorption

For absorbing nanoparticles, the deposited optical power is calculated from the absorption cross-section,

\[
P_{\mathrm{abs}} = I\,\sigma_{\mathrm{abs}},
\]

where \(I\) is the incident optical intensity and \(\sigma_{\mathrm{abs}}\) is obtained from Mie theory.

Material optical properties can be supplied either directly through a complex refractive index or through wavelength-dependent optical data stored in the corresponding material database.

A quasi-static approximation is also implemented for validation and comparison in the small-particle regime.

## Thermal model

The solver calculates the transient temperature field generated by the absorbed optical energy.

A finite particle–medium interfacial thermal conductance can be included, allowing the thermal resistance of the interface to be explicitly considered.

The complete temperature matrix returned by the solver contains the temperature evolution as a function of both radial position and time.

## Project status

The previous release of the software, **v0.1.0**, was archived on Zenodo and is available at:

https://doi.org/10.5281/zenodo.18381150

Version **v1.0.0** represents the first major release of the actively maintained codebase and substantially extends v0.1.0 by incorporating optical absorption calculations based on Mie theory, finite interfacial thermal conductance, numerical validation tools, improved matrix conditioning, and a reorganized software structure.

Further development will focus on stratified spherical nanoparticles, including core-shell and multilayer systems and layer-resolved optical absorption.
