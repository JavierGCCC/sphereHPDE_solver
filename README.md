# sphereHPDE_solver

`sphereHPDE_solver` is a MATLAB code for the numerical solution of heat diffusion in spherical geometries.

The thermal problem is solved using dedicated continuous-wave (CW) and transient finite-difference formulations. Transient calculations employ a Crank–Nicolson scheme, while CW calculations are solved directly from the stationary heat equation.

Version **v1.1.0** introduces a unified CW/transient solver architecture, spectral–thermal factorization, numerical verification routines, solution-analysis tools, and an inverse preconditioning procedure.

## Main features

The current implementation includes:

- Numerical solution of the spherical heat diffusion equation using a Crank–Nicolson finite-difference scheme.
- Unified interface for continuous-wave and transient thermal calculations.
- Factorized representation of the thermal response, allowing efficient reconstruction of the temperature field as a function of the radial position, time and wavelength.
- Independent thermophysical properties for the nanoparticle and surrounding medium.
- Finite interfacial thermal conductance (ITC) at the particle–medium interface.
- Optical absorption cross-section calculated using Mie theory.
- Wavelength-dependent optical properties obtained from interpolated material data.
- Mie calculations performed using the third-party MATLAB package **MatScat**.
- Sparse truncated-inverse preconditioning for improving the conditioning of the thermal system matrices.
- Initialization routine for automatically configuring the MATLAB paths required by the solver.
- Automatic numerical and physical verification routines.
- Tools for reconstructing radial temperature profiles from CW and transient solutions.
- Example: Au sphere in water under CW illumination for perfect gold/water thermal contact and finite interfacial thermal conductance.

## Repository initialization

Before using the solver, initialize the required MATLAB paths by running:

```matlab
initialize;
```

The initialization routine makes the solver modules and required MatScat routines available in the current MATLAB session.

Example script is provided in the `examples/` directory.

## Optical absorption

For absorbing nanoparticles, the deposited optical power is calculated from the absorption cross-section.

Material optical properties can be supplied either directly through a complex refractive index or through wavelength-dependent optical data stored in the corresponding material database.

A quasi-static approximation is also implemented for validation and comparison in the small-particle regime.

## Thermal model

The solver calculates the continuous wave and transient temperature field generated by the absorbed optical energy.

A finite particle–medium interfacial thermal conductance can be included, allowing the thermal resistance of the interface to be explicitly considered.

The thermal response is stored in factorized form and can be reconstructed for selected wavelengths and, in transient calculations, selected times. For CW calculations, the time dependence is omitted.

## Verification

The verification suite includes:

- Transient-to-CW convergence. 
- Quasi-static optical-limit checks.
- Analytical CW thermal validation. 
- Linearity checks.
- Verification of the inverse preconditioner.

## Examples

- CW heating of a gold nanosphere in water under 1e9 W/m^2, comparing perfect thermal contact with finite ITC.

## Project status

The previous release of the software, **v0.1.0**, was archived on Zenodo and is available at:

https://doi.org/10.5281/zenodo.18381150

Version **v1.0.0** was the first major release of the actively maintained codebase and substantially extends v0.1.0 by incorporating optical absorption calculations based on Mie theory, finite interfacial thermal conductance, numerical validation tools, improved matrix conditioning, and a reorganized software structure.

Version **v1.1.0** further extends the capabilities of the previous version incorporating new verification, visualization and analysis tools.
